# 0007 The map as a showcase of its own (confref-map)

Status: accepted · Date: 2026-11-09

## Decision

- The map is the repository `confref-map`: a static page, built by `build.py` (standard library) from the index of
  the application into `/map/` (`services/jobs.sh map` after each load); no requests to other sites, the base map
  (Natural Earth, public domain) included.
- It draws the events placed in a city or region (confref-data 0018) as circles per place, with filters for academic
  field, field, discipline, series and years, a histogram of the years, a play mode through the years, the events of
  a place in a panel with links to their landing pages, and the path of a series in time. Its state is in the
  address (`#e=<event>`, `#s=<series>`, `#y=<from>-<to>`), so that the landing pages can link to it.
- Events placed only by country and events without a place are counted, not drawn.
